# YSite-forger

Визуальный конструктор сайтов в тёмной ч/б теме с встроенной лабораторией фонов BG·LAB.

## Состав

- `site-builder/` — сам конструктор (открой `site-builder/index.html` в браузере):
  - главная (создать сайт / сохранить фон / экспорт),
  - редактор (блоки, страницы, настройки, экспорт HTML/ZIP),
  - **BG·LAB** — редактор фонов: слои, фигуры, символы, курсор-FX, экспорт SVG/CSS/HTML.
- `background-site/` — отдельная лаборатория BG·LAB (исходник, резервная копия).

## Возможности

- Работа полностью в браузере, ничего устанавливать не нужно (file:// или любой статик-хостинг).
- Проект и сохранённые фоны хранятся в localStorage браузера.
- Экспорт: одностраничный HTML или полный проект ZIP.
