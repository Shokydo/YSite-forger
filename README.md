# YSite-forger

Визуальный конструктор сайтов в тёмной ч/б теме со встроенной лабораторией фонов BG·LAB.

Открой `index.html` в браузере — ничего устанавливать не нужно.

## Возможности

- Главная: создать сайт (HTML или ZIP), применить сохранённый фон.
- Редактор: блоки, страницы, настройки, экспорт одностраничного HTML или полного проекта ZIP.
- **BG·LAB**: редактор фонов — слои, фигуры, символы, курсор-FX, экспорт SVG/CSS/HTML.

Проект и сохранённые фоны хранятся в localStorage браузера.
